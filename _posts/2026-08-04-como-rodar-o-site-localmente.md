Para visualizar o site no seu computador antes de publicá-lo, siga os passos
abaixo.

## 1. Instale as dependências

Certifique-se de ter o Ruby instalado e rode:

```bash
bundle install
```

## 2. Inicie o servidor local

```bash
bundle exec jekyll serve
```

## 3. Acesse no navegador

Abra [http://localhost:4000](http://localhost:4000) para ver o site rodando,
com atualização automática a cada alteração nos arquivos.
