Este é o primeiro post do blog, gerado automaticamente ao criar o projeto.

O Jekyll transforma arquivos Markdown como este em páginas HTML estáticas.
Para criar um novo post, basta adicionar um arquivo em `_posts/` seguindo o
padrão de nome:

```
AAAA-MM-DD-titulo-do-post.md
```

E incluir um cabeçalho (front matter) no topo do arquivo, como o deste post:

```yaml
---
layout: post
title: "Título do post"
date: AAAA-MM-DD HH:MM:SS -0300
categories: geral
---
```

A partir daí, é só escrever o conteúdo em Markdown normalmente.
